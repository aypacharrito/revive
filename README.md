# REVIVE v0.9 — website download and donations repair

**Start here:** double-click `RUN_NOW.bat`, paste your GitHub Desktop repository location, type `IMPORT`, then commit and push in GitHub Desktop. The importer never launches or installs Electron.

The public page now removes the source code button, never redirects a nonexistent installer button to GitHub, and only enables the direct `.exe` download once an actual release asset exists. Donations connect by the Vercel `DONATION_URL` environment variable after the owner creates a valid REVIVE-specific checkout. See `docs/INSTALLER_AND_DONATIONS.md`.

**Important:** This package does not contain an actual compiled installer, and live payments have not been activated.
